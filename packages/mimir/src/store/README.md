# Storage

The MimirDatabase wrapper supports the optional Rust Node addon and better-sqlite3. Shared tables follow the distribution Soul 9.2 Mimir contract. Additional learning tables have module-specific version keys.

배포판 Soul과 공통 테이블을 연동하며, 추가 학습 기능은 별도 버전 키로 관리합니다. 필드와 마이그레이션 범위는 루트 문서에 정리되어 있습니다.
